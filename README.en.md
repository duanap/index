# Kanade + EmDash

Kanade with EmDash 1.2.0 and Astro 7.3.7: live published content, Node 24, SQLite, local media and automatic WebP derivatives. Requires pnpm 10.33.0. Languages: zh-CN, en, ja.

See [README](README.md) and [deployment guide](docs/deployment.md). Upstream: [Kanade](https://github.com/sudoriaa/Kanade-Astro), commit `4cc05cc61c58abc4f5ff8c3426fea56550f393e5`, and [EmDash](https://github.com/emdash-cms/emdash).
