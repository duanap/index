# Kanade 接入 duanap/emdash 新增功能

日期：2026-10-09。用户已确认功能差异清单，并回复“按计划直接实现”，批准本设计与实施计划。

## 目标与边界

在当前 duanap/index 中接入已完成的自定义后台、会员、互动、评论留言、生活记录、作品、归档、CMS 友链、首页轮播、备案页脚及网站地图管理。界面继续使用 Kanade 的配色、布局、响应式行为和 Vue 交互。

来源固定为 duanap/emdash 的 `codex/upgrade-emdash-1.2.0` 提交 `bb448eaf26e76a6d6ff55042f9031222dd010239`；其 core/admin 都是 1.2.0。当前基线是 index main 的 `e58526f201bae103763e5e3b5f7c0749be78c38f`，上一轮本地部署文档和 CMS 后台等待修正需要保留。

本轮交付本地代码、可复现依赖、迁移工具、测试与运维说明。正式数据库迁移和生产发布另按已验证的产物、备份与明确操作范围执行。QQ 真实账号授权需有效应用配置和账号；模拟授权测试不能代替它。

## 固定的技术约束

- Astro 7.3.7、EmDash 1.2.0、Node 24、项目 pnpm 10.33.0；Fork 构建工具链遵循其固定 packageManager。
- 单 Node 服务、SQLite 和本地图片，不新增 Docker、CI 或付费服务。
- `KANADE_DATA_DIR`、现有加密密钥、文章、页面、管理员和上传文件继续保留。
- 当前 `/posts/{slug}/`、单语言展示、草稿和预览隔离、SEO、RSS 与 sitemap 保持兼容。
- 发布、撤回、设置和审核结果在新请求中立即生效；不加入 fork 示例的 60 秒页面缓存。
- JPEG/PNG 上传原字节保留，服务器生成质量 82、最长边 2560 的 WebP 衍生文件；SVG、GIF、动画和已有 WebP 使用现有保留策略。
- 不导入旧博客数据库；历史本机留言不自动公开到服务器。

## 自定义框架交付

使用固定源码构建 core/admin，产物置于 `vendor/`，记录来源 SHA、包版本、补丁及 SHA256。项目通过本地包依赖和对 admin 的覆盖解析这对同源包；发布后的服务器只解包，不构建单体仓库。

接入 fork 的分组导航、中文错误信息、Lucide 后台图标、内容编辑与分页改进、留言编辑、回收站批量操作和设置分组。保留其 trusted native raw route 的多个 Set-Cookie 与 OAuth 跳转支持，sandboxed route 的限制保持原样。

应用专用补丁移除 admin 在上传前调用 `prepareWebpUpload` 的两处转换，使原图仍进入当前 `kanade-webp` 服务端处理流程。`.html` 后缀功能保持关闭。提供必要的图标兼容适配，覆盖组件库内部图标，而不替换 Kanade 前台的既有装饰资源。

## 内容模型与非破坏性升级

保持 posts/pages 原字段、原 ID 和原内容。增加以下集合：

| 集合     | 字段                                                                               | 公开入口                             |
| -------- | ---------------------------------------------------------------------------------- | ------------------------------------ |
| life     | title、excerpt、content、date、featured_image                                      | `/life/`、`/life/{slug}/`            |
| projects | title、excerpt、content、date、featured_image、project_type、project_url、featured | `/projects/`、`/projects/{slug}/`    |
| wall     | title、content，启用原生评论                                                       | `/messages/`；集合条目预览回到该入口 |
| friends  | title、description、url、icon、color、label、order                                 | `/friends/`                          |

life 添加独立标签分类法；projects 的类型通过已有 select 字段管理，允许的自定义多选只在实际需要的标签字段显式开启。新增内容继续支持草稿、修订、预览、定时发布、搜索和 SEO。

友链采用结构化集合以保留现有 Kanade 卡片，初始记录来自本项目默认友链；已有 CMS 友链不覆盖。wall 使用最早的已发布配置语言条目作为评论容器，通过数据库 ID 关联评论，条目改名不导致留言消失。

迁移命令读取明确的目标数据库，提供 dry-run，检查已有结构，只添加缺失的集合、字段、分类法和必要初始记录。现有同名结构不兼容时失败并说明，不删除或重建。正式应用前须有可恢复的 SQLite、媒体及密钥备份；重复迁移不会覆盖内容编辑或重置配置。

## 公开页面与信息流

新增生活、作品及年/月归档，复用当前内容适配、Portable Text、SEO 和 WebP 解析。列表查询覆盖全部游标页，仅展示配置语言的已发布内容。归档按有效的内容日期排列，缺失内容返回真实 404。

首页保留现有文章筛选交互，增加生活和作品入口/区块。RSS 和 sitemap 纳入新的可公开内容，排除后台、会员私有页、草稿及 noindex 内容。现有文章详情和数据形状保持兼容。

CMS 友链仍渲染 Kanade 的卡片。链接仅允许 HTTP(S) 或明确的站内路径，拒绝脚本协议；图标和颜色使用支持的映射，标题与说明通过框架转义。

## 会员、互动与留言

迁移来源的 duanap-members native 插件到本项目的插件目录，使用本项目实际 origin 和规范的 entrypoint。QQ 配置通过插件后台维护，Secret 仅写入加密设置，不在状态接口或界面回读明文。

保留 OAuth state 的 Cookie/KV 双校验、一次性消费与有效期；会员会话使用 HttpOnly、SameSite 和正式 HTTPS Secure Cookie。安全的 returnTo 只回本站，退出和修改类请求校验来源与 CSRF，会员权限与 CMS 管理员权限分开。

提供 `/login/` 与 `/member/`，支持昵称、头像和简介编辑、收藏列表、互动计数与本人评论。用户手动改过的资料不被后续 QQ 登录覆盖。私有收藏与评论归属不能通过伪造会员 ID 获取。

文章、生活和作品添加点赞/收藏，评论添加点赞。URL 使用 slug，互动使用数据库内容 ID；目标必须是有效的公开内容。计数分别处理点赞与收藏，长列表使用游标分页，重复或并发操作保持一致。

文章与生活等详情接入原生评论。留言墙保持 Kanade 卡片风格和色彩，新增提交保存在 CMS；访客提交审核后公开，站主后台添加可直接发布。未批准的留言不出现在公开 HTML、API 或滚动副本中。历史 localStorage 不自动上传或删除。

## 轮播、页脚和设置

首页复用 Kanade 顶部区域显示配置的轮播；无配置时保留原欢迎区域，单图时不自动切换。复用 fork 的管理设置：最多 8 张图片/链接、2–60 秒间隔、模糊、遮罩、九种文字位置、电脑与手机高度和字号。图片使用本项目 WebP 衍生 URL，保留原图读取权限。

轮播支持前后切换、圆点、键盘、触摸和暂停；焦点进入、悬停、页面隐藏时暂停，减少动态效果偏好默认不自动播放。移动端没有横向溢出，文字保持可读。

页脚读取后台 `footerLinks`，显示实际填写的备案或其他链接与图标；空设置保留当前页脚，不生成虚构备案信息。后台各设置页只提交自己的字段，保存轮播不覆盖网站标题，保存常规设置不清空轮播。

地图管理对接当前真实动态 sitemap；后台按钮结果不能指向不存在的路径，且需要管理权限。所有设置更新均通过现有设置查询生效。

冻结安装与包来源校验；类型检查、生产构建、格式及原有单元/桌面/手机/CMS 回归通过。使用隔离临时库验证模型迁移重复执行、内容与密钥保留，以及生命周期、上传原图/WebP、菜单、设置和地图行为。

新增实际运行测试覆盖 native route 多 Cookie、sandboxed route 限制、OAuth state/returnTo/CSRF、会员资料和私有分页、互动并发、留言审核与改名、批量操作部分失败，以及三种配置语言的公开内容隔离。界面验证覆盖桌面、手机、无 JavaScript 阅读和减少动态效果。

实现按几个可独立测试的任务推进，最后对完整分支进行一次独立审查。生产用户初始化/passkey 和真实 QQ 授权作为明确的外部验收项报告，不能以模拟流程标记完成。
