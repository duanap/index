# Kanade + EmDash

Kanade の外観を維持し、EmDash 1.2.0 で記事・ページ・画像を管理します。Astro 7.3.7、Node 24、SQLite とローカルストレージを使用。公開後の再ビルドは不要です。JPEG/PNG は WebP を自動生成し、元画像を保持します。pnpm 10.33.0 が必要です。

[README](README.md) と [デプロイ手順](docs/deployment.md) を参照。テーマ：[Kanade](https://github.com/sudoriaa/Kanade-Astro)、コミット `4cc05cc61c58abc4f5ff8c3426fea56550f393e5`。CMS：[EmDash](https://github.com/emdash-cms/emdash)。
